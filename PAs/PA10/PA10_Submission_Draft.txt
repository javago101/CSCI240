QUESTIONS

Question 1: The Huffman code is an example of prefix code. Explain the meaning of prefix code.
Answer: A prefix code (or prefix-free code) is a coding system where no code word is a prefix of any other code word. This crucial property allows the encoded message to be unambiguously decoded without needing special separator markers between characters.

Question 2: Explain the main difference between standard tries and compressed tries. How much space is saved by moving from the standard tries to the compressed tries?
Answer: The main difference is that a compressed trie merges any internal node that has only one child with that child, converting long chains of single-child nodes into a single node storing a substring. This reduces the total number of nodes from O(N), where N is the total length of all strings, to O(s), where s is the total number of strings stored. Space is significantly saved because the compressed trie guarantees at most 2s - 1 nodes in total, reducing space complexity to be proportional only to the number of strings rather than the sum of their lengths.
